# 观象

中西术数的排盘动画：奇门遁甲、大六壬、太乙神数（三式）、八字、梅花易数、六爻、小六壬、塔罗与西方占星本命盘的排盘演示。每一式先只填时间和所问，起盘后把推演过程分八步做成动画，最后生成一段完整的盘面文字，可以交给 AI 或懂行的人解读。

## 使用

```bash
npm install
npm run dev      # 本地开发
npm test         # 规则测试（古籍课例、外部软件对照、随机课例逐条核对）
npm run build    # 打包成一个独立的 dist/index.html
```

`dist/index.html` 不依赖任何外部资源，直接放到网站上即可。地址后加 `#qimen`、`#liuren`、`#taiyi`、`#bazi`、`#meihua`、`#liuyao`、`#xiaoliuren`、`#tarot`、`#natal` 可直达对应页面；`#calendar` 为农历日历，`#history` 为起盘记录。

## 结构

```
src/
  core/            天文与历法：太阳视黄经、节气、ΔT、真太阳时、四柱干支、农历（定朔与无中置闰）
  arts/
    common.js      三式共用的设置项（换日、真太阳时）与影响提示
    qimen/         奇门遁甲：core.js 算法，board.js 盘面动画与讲解，index.js 设置项与说明
    liuren/        大六壬
    taiyi/         太乙神数
    bazi/          八字
    meihua/        梅花易数
    liuyao/        六爻
    xiaoliuren/    小六壬
    tarot/         塔罗（cards.js 牌库，art.js 自绘牌面）
    natal/         西方占星本命盘（places.js 城市与时区，impacts.js 设置影响）
  ui/
    Shell.jsx      共用外壳：起式页、设置面板、八步动画调度、跳过、结果页
    FancySelect.jsx 带说明的下拉
    anim.js        动画时间轴（定时器与逐帧补间，可一次取消）
    share.js       盘面截图：把盘面排成卡片导出 PNG（html-to-image）
  pages/Home.jsx   首页（含今日农历与下一节气）
  pages/History.jsx 起盘记录（ui/history.js 存取，只存在本机浏览器）
  pages/Calendar.jsx 农历日历（core/almanac.js：农历、干支、节气与月相时刻、节日）
tests/rules.test.js
tests/fixtures/natal-swe.json  本命盘对照数据（Swiss Ephemeris 生成）
```

新增一式时，在 `src/arts/` 下建同样的三个文件（算法、盘面、配置），再加进 `src/arts/index.js` 和首页卡片。

## 口径

- 奇门：时家转盘；定局可选拆补、置闰、茅山；中五寄宫、八神名称、换日、真太阳时可配置。古籍克应（`qimen/keying-data.js`）逐宫列十干克应 81 条、八门静应 64 条、门迫制和义、九星旺相休囚废（默认按月令，可改按落宫）、星宫生克与八神性质，条文据调研资料录自《奇门遁甲秘笈大全》《奇门遁甲统宗》《御定奇门宝鉴》《烟波钓叟歌》，异说并列，缺文不补；值符真甲叠加可开关。只录条文，不作综合判断。
- 大六壬：月将以中气精确时刻换将；取传顺序为伏吟/返吟 → 贼克 → 比用 → 涉害（《六壬大全》数深浅）→ 八专 → 遥克 → 别责 → 昴星。
- 太乙：《太乙统宗宝鉴》派，时计、岁计；定算、四神、天乙、地乙、直符、飞符、四郭固杜、月计、日计暂不排。
- 八字：立春换年、节换月；子时换日可选 23 点或 0 点（分早晚子）；起运按出生到相邻节的精确时刻，三天折一年；长生阳顺阴逆。只排盘，不断吉凶。

各项口径的依据与对照用例见 `tests/rules.test.js`。
- 梅花易数：时间起卦用农历年支数、月数、日数、时支数；亦可两数、三数起卦。先天八卦数取卦，除六取动爻，动爻所在为用。农历以天文合朔定初一、无中气之月置闰，测试对照近年春节与闰月及 2033 年难例；起卦方法以《梅花易数》观梅占核对。
- 六爻：京房纳甲。摇钱背记三、字记二，6 老阴、9 老阳为动；八宫世应、纳甲、六亲、按日干起六神、伏神取本宫纯卦同位爻、变卦、月建日辰旬空。测试以姤、复、大有、晋、涣、师之升等经典卦例核对。
- 小六壬：大安起正月，月位起初一，日位起子时，起数之位算一；亦可报三数起课。测试确认与速算公式（月 + 日 + 时 − 2）÷ 6 一致。
- 塔罗：七十八张，牌序按韦特体系；洗牌用加密级随机数（Fisher–Yates），牌由用户在扇形牌堆中亲手抽出，跳过时程序随机补齐并在原文中注明。牌面为本项目自绘，关键词为自撰的简短提示。
- 本命盘：行星为地心视位置，用 astronomy-engine（MIT）计算；出生地钟表时间按 IANA 时区规则换成世界时，自动处理历史夏令时（中国 1986–1991 年等），拨快空档与拨回重叠会在原文中注明。上升、天顶与 Placidus、Koch、Regiomontanus、Campanus、Porphyry、等宫、整宫七种宫制按公式自算，极圈内象限宫制改用 Porphyry；真交点取月球密切轨道升交点；恒星黄道支持拉希里、费根-布拉德利。`tests/fixtures/natal-swe.json` 是用 Swiss Ephemeris（Moshier 星历）对 50 组随机出生数据算出的对照值（只用于测试，未打包进页面），行星、宫头、交点、岁差的差别都在 30 角秒以内；莉莉丝用 Meeus 平均远地点公式，与 Swiss Ephemeris 的修正值最多差约 7 角分。
